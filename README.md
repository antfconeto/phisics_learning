# phisics_learning

Simulações de física feitas por hobby, em JavaScript puro com Canvas.

## temperature_phisics

Condução de calor em uma barra 1D usando a equação do calor
(`∂T/∂t = α · ∂²T/∂x²`) resolvida por diferenças finitas. Setas mostram
a direção e a intensidade do fluxo de calor (Lei de Fourier, `q = −k · ∂T/∂x`).

Para rodar, abra `temperature_phisics/index.html` no navegador.
